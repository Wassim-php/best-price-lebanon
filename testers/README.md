# Testers Directory

This folder contains all test scripts and sample data for testing the Best Price Lebanon scraping functionality.

## Test Scripts

### Python Test Scripts

All Python scripts can be run from this directory using:
```bash
python <script_name>.py
```

Or from the project root:
```bash
python testers/<script_name>.py
```

#### `test_detailed_pricing.py`
Tests the complete pricing extraction for iPhone 15, including:
- Item price
- Shipping fees
- Tax amounts
- Total price

**Usage:**
```bash
python test_detailed_pricing.py
```

#### `test_hp_pricing.py`
Tests pricing extraction for HP Victus laptop which has 11% VAT tax and free shipping.
Validates tax calculation works correctly.

**Usage:**
```bash
python test_hp_pricing.py
```

#### `test_checkout_flow.py`
Low-level Selenium test that verifies the checkout automation flow:
- Adds product to cart
- Opens cart overlay
- Proceeds to checkout
- Analyzes checkout page structure
- Saves checkout page HTML for inspection

**Usage:**
```bash
python test_checkout_flow.py
```

#### `test_gemini.py`
Tests the Gemini AI API connection and lists available models.
Validates that the API key is working correctly.

**Usage:**
```bash
python test_gemini.py
```

## Test Data Files

### `test_request.json`
Sample API request body for testing the `/api/product-details/961souq` endpoint with iPhone 15.

**Usage with curl:**
```bash
curl -X POST http://localhost:8000/api/product-details/961souq \
  -H "Content-Type: application/json" \
  -d @testers/test_request.json
```

### `test_hp_request.json`
Sample API request body for testing the endpoint with HP Victus laptop.

**Usage with PowerShell:**
```powershell
$body = Get-Content testers\test_hp_request.json -Raw
Invoke-WebRequest -Uri "http://localhost:8000/api/product-details/961souq" `
  -Method POST `
  -Headers @{"Content-Type"="application/json"} `
  -Body $body `
  -UseBasicParsing | Select-Object -Expand Content
```

### `checkout_page.html`
Saved HTML snapshot of the 961souq checkout page (generated by `test_checkout_flow.py`).
Useful for debugging and understanding the checkout page structure without running automation.

## Running Tests

### Prerequisites
Make sure you have the virtual environment activated and dependencies installed:

```bash
# Windows
.\.venv\Scripts\Activate.ps1

# Install dependencies if needed
pip install -r requirements.txt
```

### Quick Test Suite
Run all core tests:

```bash
python testers/test_gemini.py          # Test AI integration
python testers/test_detailed_pricing.py # Test iPhone pricing
python testers/test_hp_pricing.py      # Test laptop with tax
```

## Notes

- All Python test scripts automatically add the parent directory to `sys.path`, so they work from any location
- Selenium tests run in headless mode by default
- API tests require Docker containers to be running: `docker-compose up -d`
- Test execution times vary: checkout automation takes 20-30 seconds due to page loads and AJAX waits
